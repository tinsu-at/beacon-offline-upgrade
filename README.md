# Beacon of Growth

# Build Beacon – Phase 1 (Foundation)

Create a modern, premium web application called **Beacon**.

## Mission

Beacon is a personal growth companion that helps users become disciplined, confident, productive, and lead by example. It is not just a chatbot—it is a coach, mentor, accountability partner, and personal assistant.

## Design

Create a clean, premium UI inspired by ChatGPT, Apple, and Notion.

Requirements:

- Responsive design

- Forest Green (#1E3A2F) as the primary color

- Gold (#D4AF37) as the secondary color

- Beige (#F5F5DC) as the accent color

- Follow the 60-30-10 color rule

- Rounded cards

- Smooth animations

- Light and Dark Mode

- Elegant typography

- Accessible design

## Authentication

Use Supabase Authentication.

Create:

- Sign Up

- Login

- Forgot Password

- Logout

## Dashboard

After login, display:

- Personalized greeting

- Current date

- Quote of the Day

- Today's Top Priority

- Today's Confidence Challenge

- Habit Progress

- Weekly Streak

- Quick Action Cards

## Navigation

Create navigation for:

- Dashboard

- Tasks

- Habits

- Journal

- Goals

- Progress

- Settings

## Daily Planner

Allow users to:

- Create tasks

- Edit tasks

- Delete tasks

- Mark tasks complete

- Set priority

- Set due dates

## Habit Tracker

Default habits:

- Study

- Coding

- English Practice

- Exercise

- Reading

- Prayer

- Water Intake

- Sleep

Allow users to add custom habits.

Track daily streaks.

## Confidence Challenge

Generate one confidence challenge each day.

Examples:

- Talk to one new person.

- Practice English for five minutes.

- Ask one question.

- Introduce yourself confidently.

At the end of the day ask:

- Did you complete today's challenge?

- What did you learn?

- Confidence level (1–10)

Store the answers.

## Journal

Create a beautiful journal page where users can write daily reflections.

## Goals

Allow users to create:

- Short-term goals

- Long-term goals

- Milestones

- Deadlines

## Settings

Include:

- Profile

- Theme (Light/Dark)

- Notification preferences

## Beacon Principle

Every evening display this reflection:

"Did your actions today make you someone a child would be proud to imitate?"

If Yes:

Congratulate the user and encourage consistency.

If No:

Do not criticize. Ask:

"What is one thing you can improve tomorrow?"

## Technical Requirements

Use:

- React

- TypeScript

- Tailwind CSS

- Supabase

- Component-based architecture

- Clean folder structure

- Responsive design

- Production-ready code

Do NOT build AI chat, voice conversations, long-term memory, mobile app support, or external integrations yet. Instead, structure the project so these can be added easily in future phases.
